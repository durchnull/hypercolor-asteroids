The rules themselves were altered: The tally is checked on disk and not only when it rides in a commit, because the game reads that copy and a punishment the punished can switch off between commits is not one. A ranked flight is kept as its decoded bytes in docs/tapes/<crc>.json, so the board can be recomputed like every other number in this project - the tape itself still never enters the repository. A power keyed to one pilot's name gets a word from the referee, which GR11's mirror never had. And a tape with no seat on it stops being given the benefit of the doubt once that pilot has a flight on file from a locked one.
